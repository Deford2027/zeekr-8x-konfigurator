# Конфигуратор Zeekr 8X

Страница: `index.html`. Работает без сборки и зависимостей. Чтобы посмотреть локально:

    python3 -m http.server 8931   # затем http://127.0.0.1:8931/

## Файлы
- `js/zeekr-8x-data.js`: версии, батареи, цены, цвета, диски, салоны и ракурсы. Цены и опции правятся здесь.
- `js/konfigurator.js`: логика: выбор, подмена картинок, вращение 360°, итоговая цена, заявка.
- `css/konfigurator.css`: стили (цвета и шрифты как на evolutioncar.by).
- `img/zeekr-8x/360/{цвет}--{00..35}.webp`: официальные 360°-рендеры Zeekr, 36 кадров на цвет (8 цветов).
- `img/zeekr-8x/interior/`: официальные фото салона для каждого варианта отделки.
- `img/zeekr-8x/options/`: официальные иконки цветов кузова и салона.

## Заявки
У формы есть атрибут `data-endpoint=""`. Если вписать туда URL обработчика, заявка уйдёт туда POST-запросом в формате JSON
(поля name, code, phone, config, source, page). Пока атрибут пустой, заявка только пишется в консоль браузера.

## Ссылка на конфигурацию
Выбранная сборка сохраняется в адресе, например `#v=shadow&b=70&p=hunter-blue&w=22-lingbo&i=black-orange`.
Такой ссылкой можно поделиться.
